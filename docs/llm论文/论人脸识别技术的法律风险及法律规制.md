

**摘要：**  随着人脸识别技术的广泛应用，个人信息保护面临前所未有的挑战。本文以我国“人脸识别第一案”为例，通过对案件焦点的分析，探讨人脸识别技术存在的法律风险，接着分析《民法典》的法律规制在此领域的适用，并比较欧盟《通用数据保护条例》（GDPR）及美国州法对人脸识别技术法律规范的规制路径。

【关键词】：人脸识别；个人信息保护；法律风险；民法规制

**一、引言**

随着人工智能与大数据技术的迅猛发展，人脸识别技术已经广泛应用于安防、支付、考勤等场景，极大地便利了社会生活。然而，伴随着人脸识别的广泛部署，个人信息的安全性问题也日益突出。公共空间、商业活动、教育和医疗系统中，大量面部信息在未明确授权的情况下被采集、存储、分析，引发了对隐私权和个人信息权利的强烈关注。

2020年，杭州发生的“人脸识别第一案”被广泛认为是中国司法界对人脸识别合法性问题的首次正面回应。本案不仅具有开创性判例意义，也折射出我国在数字法治治理中面临的核心问题：在技术进步的时代背景下，法律该如何保护个人信息安全？

本文通过分析“人脸识别第一案”的争议焦点，分析人脸识别技术存在的法律风险，并探讨中外现行法律对此的规制。

**二、案情简介**

2019年，郭兵在杭州野生动物世界办理了一张价值1370元的年卡。起初，管理方采用指纹识别系统作为游客入园的验证方式，后来将验证方式更改为人脸识别，并彻底取消了指纹识别选项，意味着若不进行人脸扫描，将无法进入园区。郭兵对此表示反对，他认为面部信息属于高度敏感的生物特征数据，一旦被泄露或不当使用，可能对个体的人身及财产安全造成威胁。郭兵认为，园区在未征得用户同意的情况下更改验证方式，构成对个人信息的强制采集，遂以此为由将动物世界起诉至法院。

在该案件中，由于审理时尚未出台《民法典》，且尚无专门法律针对人脸识别技术进行规制，郭兵主要依据《消费者权益保护法》《合同法》及《民法总则》等现行法律，主张动物世界存在违约及欺诈行为，并向法院请求判令其承担经济赔偿责任，同时要求删除与其相关的全部个人信息数据，包括姓名、身份证号、电话号码、照片及指纹信息。

浙江省杭州市富阳区人民法院在一审判决中指出，本案主要存在的争议焦点之一为：原告是否有权要求对其已被采集的个人信息予以删除，即人脸识别与个人信息保护是否冲突。本文围绕此项争议，探究人脸识别技术应用是否会对个人信息权造成侵害及中外法律救济途径。本案的审理具有重要意义，是我国司法实践中首次对“人脸识别构成敏感个人信息”作出明确判断，并同时强调“知情并同意”应作为此类数据处理的基本前提。

**三、法律风险**

“人脸识别第一案”所引发的法律争议，根源在于人脸识别技术所采集数据的高度敏感性，与实际应用中对信息主体权利的系统性忽视之间的矛盾。以下从本案的三个核心争点出发，逐一梳理人脸识别技术在法律层面所蕴含的主要风险。

### （一）人脸数据构成个人敏感信息的风险

本案的核心争议之一，在于对园方所采集人脸数据的法律性质之认定。园方主张人脸数据不构成“个人敏感信息”，进而拒绝承认郭兵对其面部数据被采集享有知情同意的权利。富阳区人民法院在判决中明确认定，园方将人脸数据与特定游客身份相绑定、单方更换识别方式的行为，超出了必要原则的允许范围，不具有正当性，应当保障信息主体的知情同意权利。

这一司法认定与《中华人民共和国个人信息保护法》第28条的规定相契合，因面部识别信息一旦泄露或非法使用，可能导致人格尊严受到侵害，该条款明确将面部识别信息列为“敏感个人信息”，要求信息处理者承担合法性、正当性与必要性审查义务。学者邢会强进一步指出，人脸识别系统采集的数据具有不可替代性与不可更改性，其风险等级甚至高于传统隐私信息，理应优先纳入“高度保护范畴”[[1]](#_ftn1)。

尽管部分学者对人脸是否具备隐私性持有反对意见，如学者Hartzog 与 Selinger曾指出，“人脸本身并不具备隐私性，只有在其被结构化、算法化并绑定身份时，才构成侵犯隐私的工具”[[2]](#_ftn2)。但是，这一观点在本案语境下恰恰印证了法院的判断：正是园方的系统性采集与身份绑定行为，使原本属于公共可见的面部信息转化为具有高度识别能力的个人敏感数据，由此产生了相应的法律风险。

由此可见，无论人脸数据在未绑定身份时是否单独构成个人敏感信息，当园方将人脸数据与特定身份相绑定，便已对信息主体的人格权益构成潜在侵害。因此，无论采集行为是否直接造成实际损害，信息主体的知情同意权均应受到法律保障。

### （二）人脸识别技术的使用忽视被采集者知情同意权的风险

本案中，园方在变更身份验证方式时，采取的是单方面通知而非征求同意的方式。园方以“升级管理系统”为由，将原有指纹识别系统替换为人脸识别系统，并拒绝用户继续使用原方式的申请。郭兵不仅未获得充分的事先告知，更缺乏实质性的拒绝权利与替代选择空间，其知情同意权本质上已经被园区以管理升级的名义所架空。

富阳区人民法院对此明确指出，园方的行为违反了处理敏感个人信息时应遵循的比例原则与最小必要原则，并据此判令园方删除郭兵的人脸信息。这是我国司法实践中首次明确将“充分告知并取得明确同意”确立为处理敏感个人信息的实质性前提，具有重要的先导价值。

同时，本案所揭示的知情同意机制缺失具有普遍性，并非个案偶然。正如学者石佳友与刘思齐所指出的，在人脸识别数据的实践使用中，信息控制者往往通过格式合同、软件默认条款等方式规避用户的主动选择权，实质上将知情同意机制“工具化”，从而违背了立法原意[[3]](#_ftn3)。郭兵案所暴露的，正是技术部署与法律保障之间结构性落差的典型表现：当同意被简化为格式条款的默认勾选，知情同意的实质权利便已消失。

### （三）人脸识别技术泄露个人隐私信息的风险

本案中，郭兵的核心顾虑并不仅限于入园方式的改变，更在于人脸数据一旦被园方采集，其后续的存储、使用乃至泄露风险将完全脱离信息主体的控制。郭兵无从知晓这些数据将被保存多久、以何种方式存储，以及是否可能因技术漏洞或商业合作而流向第三方。

这一顾虑具有充分的现实依据。生物识别信息具有“不可更换性”与“可精确标识性”，有别于密码或账号，人脸数据一旦泄露便无法更改，且可被永久用于识别特定个体，足以被用于欺诈、追踪乃至歧视性分析。人脸识别技术作为一种典型的无感知采集技术，进一步加剧了这种风险：信息主体往往在不知情的情况下即被采集，对信息的后续流向几乎丧失控制能力。

因此，信息主体的同意不应仅仅被形式化为简单的签字或点击，而应体现为对数据处理行为的实质性理解与自主授权。本案中，园方对于解释义务的履行并不充分，导致郭兵无从对新技术带来的隐私风险形成合理预期；加之园方并未提供任何替代人脸识别采集的方案，才导致这一服务纠纷上升为具有公共意义的法律问题。人脸识别技术的隐私泄露风险，不仅是技术层面的挑战，更折射出当前信息处理法律实践中对隐私保护义务的系统性忽视。

**四、民法规制分析**

### （一）《民法典》规制框架在本案中的适用与局限 

富阳区人民法院的判决，主要依托《民法典》第一千零三十四条至第一千零三十八条关于人格权保护的一般性规定，确认人脸数据属于敏感个人信息，并以“合法、正当、必要”作为审查园方行为合法性的基本标准。法院认定，园方单方更换识别系统、强制采集人脸信息的行为违反了最小必要原则，并据此支持郭兵要求删除个人信息的诉求。这一判决的前瞻性意义在于，在2021年生效的《个人信息保护法》正式施行之前，通过《民法典》人格权框架对人脸识别行为作出了实质性的合法性审查，体现了我国司法机关面对数据时代治理转型时的敏锐回应。

然而，《民法典》的规制框架在应对人脸识别技术挑战时，存在三方面较为明显的局限。其一，《民法典》以事后救济为主要路径，缺乏对信息处理行为的事前审查机制：本案中，园方的人脸识别系统在被诉前已实际运行，郭兵的权利已处于受损状态；其二，在举证责任分配上，信息主体须自行证明损害与信息处理行为之间的因果关系，而人脸数据的不当使用往往难以被当事人感知或证明；其三，《民法典》的人格权保护条款较为原则性，在认定“必要性”边界等具体问题上仍有赖于法官的自由裁量，缺乏可操作的量化标准。正如学者程啸所指出，有必要制定专门的个人信息保护法，对个人信息处理加以更详细具体的规范，这一判断的必要性，在本案的司法困境中得到了充分印证；固然，“人脸识别第一案”引发的公众热议，显示出我国法律已经面临如何正确保护个人敏感信息的问题，即在生物识别技术广泛应用的时代，法律规范该如何回应“知情同意”“必要性”“合法处理”等核心要求[[4]](#_ftn4)。这些局限使得在技术手段日益复杂的背景下，仅凭《民法典》难以为信息主体提供充分且及时的法律保护，亦凸显了细化专门立法与更完善规制路径的迫切需要。

### （二）比较法视野：GDPR与美国法的规制路径及其对我国的启示

 欧盟的《一般数据保护条例》（GDPR）被视为全球数据治理的“黄金标准”，其规制路径恰好弥补了《民法典》框架中事后救济模式的不足。GDPR第九条明确将生物识别信息列为“特别类别数据”，要求在取得数据主体明确同意或具备重要公共利益的前提下方可处理；更重要的是，GDPR还要求推行“数据保护影响评估”（DPIA）制度，要求数据控制者在部署高风险数据处理系统之前，须事先评估并记录潜在风险及其应对措施。若本案适用DPIA机制，园方在引入人脸识别系统之初便须完成合规评估，郭兵的权利侵害或可在事前得到防范，而非仅依靠事后诉讼。在此基础上，欧盟通过设立独立的数据保护机构（如欧洲数据保护委员会EDPB），形成了相互牵制的治理闭环。 

美国法对人脸识别技术的规制，则采取宪法性保护路径。学者Ferguson通过对多起执法领域面部识别案件的研究指出，面部识别技术对“合理隐私期待”的侵蚀构成了对第四修正案的挑战[[5]](#_ftn5)。美国法院据此开始要求执法机关在使用此类技术前进行强制披露和司法授权，从而形成基于合宪性审查的风险规避机制，其“可识别性即风险性”的理念与我国司法机关对“数据不可替代性”的认定高度契合。然而，由于缺乏统一的联邦数据保护立法，美国的监管整体上高度碎片化。

学者Hartzog与Selinger进一步指出，“企业自我规制”文化的盛行使得生物识别技术在商业领域迅速扩张，却难以形成有效问责；他们将人脸识别称为“压迫性的完美工具”，呼吁治理重点应从事后同意机制转向技术源头的风险管控[[6]](#_ftn6)。

相较于上述两种路径，我国在《民法典》与《个人信息保护法》中已确立了个人数据的敏感性分级、明示同意与用途限制等制度规则，对企业和平台提出了更明确的合规义务。在监管架构上，我国虽未设立类似EDPB的独立第三方机构，但通过“公私二分”的解释路径，初步构建了差异化的层级牵制监管体系。学者李涛认为，应将我国《个人信息保护法》第13条第1款“个人信息处理规范的适用主体包含公共部门与私营部门”解释为公私二分[[7]](#_ftn7)，即公共部门以禁止处理个人信息为原则，仅因履行法定职责、维护公共利益方可处理个人信息；私营部门以允许处理个人信息为原则，仅因违反三类禁止性规定方受限制。这一制度设计在立法精神层面与GDPR具有较高契合度，但在事前评估机制、独立监管机构设置以及跨部门法律协调等方面，仍存在显著的制度差距，有待进一步完善。

**五、未来规制路径**

通过上述分析，我国当前针对人脸识别技术的法律规制在以下四个方面存在较为突出的不足：其一，缺乏事前审查机制，现行规制框架以事后救济为主，无法在权利侵害发生前实施预防性介入；其二，举证责任分配对信息主体不利，人脸数据的不当使用难以感知与证明；其三，《民法典》规制标准仍较原则性，在“必要性”边界等核心问题上缺乏可操作的量化判断标准；其四，缺乏独立的专门监管机构，现有公私分立的监管体系与GDPR等国际标准相比，在执行合力与问责机制上仍存在明显差距。基于以上不足，本文认为，我国未来对人脸识别技术的法律规制应在以下路径上加以推进。 

在信息化的背景下，正如学者何松威所言，“将数据政策转变为数据法律，尤其是将政策上的数据权利话语转成法律上的数据权利话语，是我国目前数据法研究的主要任务。”[[8]](#_ftn8)人脸识别技术作为高度敏感的信息处理手段，其法律规制应具备三重特征：预防性、审查性与救济性，且与其他部门法结合。

学者杨猛认为，在数据三权分置背景下，以权利类型作为逻辑起点，以刑法法益作为跨法域连接要素，在规范保护目的价值引导下，会形成以典型数据法益作为保护对象的刑法规制领域[[9]](#_ftn9)。

在国际方面，学者Joh提出“自动化行政失灵”概念，指出当公共管理系统引入AI或人脸识别决策时，往往缺乏基于权利的合法性程序，形成“黑箱治理”。因此，她建议成立独立第三方技术伦理委员会，对高风险算法进行预审评估，防止权力与技术结合导致信息权滥用[[10]](#_ftn10)。这也为我国构建多中心、可解释的合规审查体系提供了可参考的路径。

我国未来对人脸识别技术的法律监管，应建立在多元要素协调基础上，不仅完善现行法律在个人敏感数据处理方面的规定，更应推动形成以立法为核心、以审查为程序、以司法为保障的数据治理制度。

**六、结语**

“人脸识别第一案”的审理与判决，标志着我国司法体系对新时代人脸识别技术的法律风险的正式回应，主要在于个人信息保护问题，也显示出新兴技术与传统法律规制之间日益突出的争议焦点。就世界范围而言，面部识别作为生物识别技术的重要一环，因其高精准性、难以更改性与无感采集特性，被普遍视为典型的敏感个人信息；与此同时，对人脸识别技术的利用在实践中频繁处于便利与侵犯个人权利的边缘，既暴露出当前各大监管体系的不足，也引发了各界学者对更新法律适用的持续思考。尽管与欧盟GDPR或美国宪法式控制模式相比，我国目前处于制度完善的阶段，但无论是民法典更新后针对人格权的保护条款，还是最新《个人信息保护法》的立法设计，都展现出我国立法与司法机制对新时代数字治理理念的逐步回应。

面向未来，如何在保障技术创新与保护个人权利之间实现真正的平衡，仍需立法、司法与社会多元主体的共同参与，构建真正具备权利尊重、程序正义与公共信任的数字法治秩序。
